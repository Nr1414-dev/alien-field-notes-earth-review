## What it does

`main.py` writes one original line of plain text — a review of planet Earth left by an alien tourist after a two-day visit — to `/output/entry.txt` (at most 200 characters, as the bounty requires).

> Pros: breathable air, friendly locals. Cons: the air is 78% filler gas and nobody warned me. Still, I inhaled.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
